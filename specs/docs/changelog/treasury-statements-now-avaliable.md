# Treasury API now supports statements

We’ve expanded the Treasury API to support statement retrieval. You can now programmatically fetch:

* Monthly statements
* Trade confirmations
* 1099s
* And more

API documentation: <https://docs.mercury.com/reference/gettreasurystatements>

If you have questions or want to see additional Treasury functionality in future releases, feel free to reach out to <api@mercury.com>.
