# n8n community node launch

We’re excited to announce the launch of our Mercury community node for n8n 🎉

You can now add Mercury triggers to your workflows when:

* A transaction is created
* transaction is updated
* An account balance changes

Install it using n8n’s community node instructions:
<https://docs.n8n.io/integrations/community-nodes/installation/>

Node package:
<https://www.npmjs.com/package/n8n-nodes-mercury>
